# JobG3tter - Decision-Oriented Dashboard Documentation

## Overview

### Purpose
JobG3tter helps users discover, track, and manage job opportunities efficiently through centralized job aggregation and advanced filtering tools.

The platform focuses on reducing the friction of job discovery by allowing users to browse opportunities from multiple sources in one interface.

---

# Primary User Goals

| User Goal |
|---|
| Access multiple job offer sources in one place |
| Find highly relevant offers quickly using advanced filtering |
| Track viewed and saved opportunities |
| Reduce time spent searching across different platforms |

---

# Product Positioning

## What Problem Does JobG3tter Solve?

Developers and tech candidates often waste time:
- switching between job platforms,
- repeating searches,
- filtering irrelevant offers manually.

JobG3tter centralizes job discovery into a single streamlined workflow.

---

## Core Product Value

> "A centralized intelligent job discovery dashboard for tech candidates."

# 2. Advanced Filtering & Search System



## Why This Exists

Job platforms often overwhelm users with irrelevant listings.

The filtering system helps users surface highly targeted opportunities quickly.

---

## Available Filters

| Filter | Purpose |
|---|---|
| Salary | Match compensation expectations |
| Country | Geographic targeting |
| City | Local opportunity discovery |
| Full-time / Part-time | Work schedule preference |
| Contract type | Internship, freelance, permanent, etc. |
| Skills | Technical stack matching |

---

## Filter Combination Support

Users can combine multiple filters simultaneously.

Example:
- Backend
- Docker
- Full-time
- Paris
- €50k+

---



## UX Rationale

Combinable filters reduce irrelevant results and accelerate decision-making.

The goal is to minimize:
- scrolling fatigue,
- irrelevant job exposure,
- repeated manual searches.
